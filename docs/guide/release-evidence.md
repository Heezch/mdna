# MDNA 发布证据与使用边界

当前建议：继续作为科研原型使用。离线打包和 wheel 专项回归有可复算入口；正式发布前仍需补齐独立结构验证、跨平台安装验证和导出格式验收。下面的几何结果与软件回归分别判断。

| 化学与拓扑 | 任务 | 现有证据 | 当前判断 |
|---|---|---|---|
| 标准 DNA 开放双链 | 沿用户路径生成模板坐标 | 固定种子三维对照；平滑后最大帧间转角 98.62°→45.17°，重原子近接触 183→23。直线对照仍有 70/94 条连接超出宽松距离范围。 | 可产生初始坐标，急弯和连接必须另行验收。序列长度缩放也会移动输入端点。 |
| 标准 DNA 双链 | 单残基锚定补缺 | 四来源套件覆盖 16/16 步，固定 1KX5 跨条目九窗均无严格候选。 | 实验接口；暂无该面板的跨条目几何阳性。 |
| 标准 RNA 单链 | 显式逐残基帧装配 | 438D 和 2G3S 的局部三残基候选已通过接回原结构的联合诊断。1RNA 和 2G3S 合计三个四残基窗口通过；同面板五、六残基无通过。 | 局部实验性证据，输入依赖已知基帧；尚无从中心线构建整链的验证。 |
| 标准 RNA 单链 | 固定实验锚点的单残基补缺 | 438D 有 4/14 窗口获模板覆盖，其中 1 窗返回候选，首选 23 重原子 RMSD 0.412 Å。2G3S 有 20/60 窗覆盖，4 窗返回候选，其中一个首选存在连接角超差。 | 局部实验接口，仍需扩大序列、构象与完整环境验证。 |
| RNA 双链、混合 DNA/RNA、修饰和其他拓扑 | 通用路径或补缺 | 当前证据没有覆盖其几何、模板、连接及输出的联合验收。 | 不作发布支持声明。 |

复核入口见 [DNA 路径](open-path-bend-qc.md)、[DNA 补缺](dna-gap-closure.md)、[RNA 显式帧](rna-path-building.md)和 [RNA 固定锚点](rna-gap-closure.md)。

下一项独立验证应记录条目与片段来源哈希、总窗口及可覆盖窗口数、实际搜索状态、首选候选的坐标偏差、连接几何与完整环境近接触。模板条目和目标条目隔离只证明条目级分离；结构家族泛化仍需额外验证。

8FEP 的 36 个四至六残基窗口在加入 438D 模板后全部有序列覆盖，原有库覆盖 15 个。当前两套库下均未进入完整装配路径评价，瓶颈是逐步帧匹配。复算见 [RNA 显式帧](rna-path-building.md)。

对 420D 的一个四残基开发窗口，末端骨架局部调整已通过现有上下文几何检查，并保存重原子坐标和键图。下一轮需在固定方法后用新窗口验证可迁移性。[420D 实验记录](rna-path-building.md)

在冻结方法和模板清单下，新条目 4JRT 有 1/48 窗进入末端双端求解，遇到共享残基位移限制。1MIS 的 24 窗均有序列模板，但都在逐步帧筛查阶段停止。两条目未得到额外的上下文通过窗口。[4JRT 原始结构](https://www.rcsb.org/structure/4JRT) · [1MIS 原始结构](https://www.rcsb.org/structure/1MIS)

## 本机离线打包核查

在已提供项目依赖、`build`、`setuptools>=69` 与 `wheel` 的 WSL 环境运行：

```bash
python -B scripts/gap_benchmarks/check_release_package.py --output artifacts/gap_benchmarks/release_package_check.json
```

脚本在临时目录准备源码包和 wheel，确认 wheel 不含本机扩展二进制，再从解包目录导入并验证版本、模板、DNA 模型及三份专项测试。测试坐标作为外部夹具复制，不计入 wheel。报告保存生成包哈希和检查结果；实际包和临时文件随运行结束清理。该检查使用已有依赖栈，不覆盖从空白环境安装依赖或 Windows 安装。

## 结构导出

标准 DNA/RNA 片段已新增 `save_mmcif()`。回读测试覆盖组件名称、坐标、显式链内连接和 RNA 全键图。导出重新分配残基编号。实际沉积系统及更广的跨软件兼容性仍待核查。

### 整条标准 DNA 双链

`model.save_mmcif(path, frame=-1)` 导出指定帧。导出保持两条链的方向、顺序和全部 MDTraj 拓扑边，按生成坐标重新分配链标和链内编号。同序列链共用实体；不同序列分别登记。Biopython 与 Gemmi 已完成 4 bp 双链回读。此接口只接受 DA/DC/DG/DT，当前不保存原有编号、晶胞、实验占有率或温度因子，也不作沉积验收。

复核命令（WSL，已有 Gemmi 的 dip2）：`conda run -n dip2 env PYTHONPATH=. python -B tests/test_duplex_mmcif.py`。离线 wheel 回归覆盖两链序列、坐标及完整显式边；Gemmi 独立核对两条链和全部连接，包括 6 条跨残基键。
